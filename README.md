# International Shipment Profitability Analysis

## Project Overview
This project analyzes international shipment data to understand revenue, costs, profitability, and delivery performance.

## Business Objectives
- Identify the most profitable countries and customers.
- Analyze shipping costs and their impact on profit.
- Measure on-time delivery and late-delivery rates.
- Develop data-driven business recommendations.

## Tools
- Microsoft Excel — Data cleaning and initial analysis
- SQL — Data querying and business analysis
- Power BI — Interactive dashboard and visualization

## Dataset
The project will use synthetic data created for learning and portfolio demonstration. It does not contain confidential company data.

## Project Status
In progress.

## Planned Deliverables
- Cleaned dataset
- Excel analysis
- SQL queries
- Power BI dashboard
- Business findings and recommendations
